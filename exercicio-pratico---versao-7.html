    Nesta configuração:

    • linhas 2–6: os caminhos de todos os arquivos JSON da aplicação. O banco de dados usado é o PostgreSQL;
    • linhas 7–20: os caminhos de todos os arquivos PHP da aplicação, na forma [chave => caminho]. Esses são os arquivos da versão 5;
    • linhas 21–32: as dependências para o cálculo do imposto, na forma de uma lista de chaves do dicionário [dependencies];
    • linhas 33–40: as dependências para a transferência dos dados do arquivo JSON [taxadmindata.json] para o banco de dados, no mesmo formato.

    Todos os caminhos são relativos à pasta [version-07]. O curso de PHP 7 adicionava a esse arquivo uma chave chamada [rootDirectory], especificando o caminho absoluto da pasta da versão na máquina do autor (["C:/Data/st-2019/dev/php7/poly/scripts-console/impots/version-07"]): ela precisava ser modificada em cada nova máquina. Os scripts agora calculam esse caminho por conta própria com base na constante [__DIR__]. A pasta [php8-oct-2026] pode, portanto, ser colocada em qualquer lugar.

    Comentários

    O código continua o mesmo da versão 6. A única diferença é o uso do arquivo [config.json] em vez das constantes:

    • Linha 10: o diretório raiz da versão 7, em relação ao qual os caminhos do arquivo de configuração são medidos. [__DIR__] é a pasta [Main] do script; [__DIR__ . "/.."] é sua pasta pai, [version-07];
    • linha 12: o caminho do arquivo de configuração;
    • linha 15: a função [file_get_contents] converte o arquivo [config.json] em uma string. A função [json_decode] usa então essa string para construir o array associativo [$config]. O segundo parâmetro, [true], da função [json_decode] especifica que se deseja um array associativo em vez de um objeto. Com a opção [JSON_THROW_ON_ERROR], um erro de sintaxe no arquivo dispara uma exceção [JsonException]. Não tentamos tratar aqui os erros de leitura do arquivo de configuração: esse arquivo faz parte da aplicação, e um erro nesse nível é um erro de programação que o próprio PHP reporta. Os erros de dados (arquivos de dados JSON, banco de dados) são sempre reportados por uma [TaxException];
    • linhas 18–20: as dependências exigidas pelo script de transferência são incluídas:
      • [$config["dependencies4transfer"]] é a tabela de dependências exigidas pelo script de transferência. É uma lista de chaves;
      • os caminhos dos arquivos a incluir estão no dicionário [$config["dependencies"]] e são prefixados com o diretório raiz. Por exemplo, a chave [TaxException] refere-se ao arquivo [version-07/../version-05/Entities/TaxException.php];
      • [require_once] (e não [require] como no curso de PHP 7) garante que um arquivo não seja carregado duas vezes, o que causaria o erro fatal "Cannot redeclare class … (previously declared in …)";
    • linhas 23–24: os caminhos completos dos arquivos de dados. O curso de PHP 7 os armazenava em constantes criadas pela função [define]. Variáveis são suficientes;
    • linha 31: o nome do arquivo que descreve o banco de dados em uso é exibido. Em uma string entre aspas duplas, o elemento de array [$config["databaseFilename"]] deve ser colocado entre chaves.

    <?php

// respeito estrito aos tipos declarados dos parâmetros e resultados das funções
declare(strict_types=1);

// namespace dos testes
namespace Application\Tests;

// as classes testadas
use Application\DaoTaxWithTaxAdminDataInDatabase;
use Application\DaoTransferAdminDataFromJsonFile2Database;
use Application\TaxAdminData;
// as classes do PHPUnit
use PHPUnit\Framework\Attributes\DataProvider;
use PHPUnit\Framework\TestCase;

final class DaoTest extends TestCase
{
    // a pasta raiz da versão 7
    private const string ROOT_DIRECTORY = __DIR__ . "/..";
    // a configuração da aplicação
    private static array $config;

    // executado uma vez, antes do primeiro teste da classe
    #[\Override]
    public static function setUpBeforeClass(): void
    {
        // recuperamos a configuração
        self::$config = json_decode(file_get_contents(self::ROOT_DIRECTORY . "/Data/config.json"), true, flags: JSON_THROW_ON_ERROR);
        // incluímos as dependências do cálculo do imposto e as da transferência de dados
        $dependencies = array_unique([...self::$config["dependencies4calculate"], ...self::$config["dependencies4transfer"]]);
        foreach ($dependencies as $dependency) {
            require_once self::ROOT_DIRECTORY . "/" . self::$config["dependencies"][$dependency];
        }
    }

    // os dois bancos de dados
    public static function databases(): array
    {
        // [arquivo de descrição do banco de dados]
        return [
            "MySQL" => ["Data/database-mysql.json"],
            "PostgreSQL" => ["Data/database-pgsql.json"],
        ];
    }

    // os dados da administração tributária lidos do banco de dados
    #[DataProvider("databases")]
    public function testTaxAdminData(string $databaseFilename): void
    {
        $dao = new DaoTaxWithTaxAdminDataInDatabase(self::ROOT_DIRECTORY . "/$databaseFilename");
        $taxAdminData = $dao->getTaxAdminData();
        // constantes de cálculo
        $this->assertSame(1551.0, $taxAdminData->halfShareQfCeiling);
        $this->assertSame(21037.0, $taxAdminData->singleIncomeCeilingForReduction);
        $this->assertSame(42074.0, $taxAdminData->coupleIncomeCeilingForReduction);
        $this->assertSame(3797.0, $taxAdminData->halfShareReductionValue);
        $this->assertSame(1196.0, $taxAdminData->singleDiscountCeiling);
        $this->assertSame(1970.0, $taxAdminData->coupleDiscountCeiling);
        $this->assertSame(1595.0, $taxAdminData->singleTaxCeilingForDiscount);
        $this->assertSame(2627.0, $taxAdminData->coupleTaxCeilingForDiscount);
        $this->assertSame(12502.0, $taxAdminData->tenPercentAllowanceMax);
        $this->assertSame(437.0, $taxAdminData->tenPercentAllowanceMin);
        // faixas de tributação
        $this->assertSame([9964.0, 27519.0, 73779.0, 156244.0, 0.0], $taxAdminData->limits);
        $this->assertSame([0.0, 0.14, 0.30, 0.41, 0.45], $taxAdminData->coeffR);
        $this->assertSame([0.0, 1394.96, 5798.0, 13913.69, 20163.45], $taxAdminData->coeffN);
    }

    // a transferência do arquivo JSON para o banco de dados, depois a releitura do banco de dados
    #[DataProvider("databases")]
    public function testTransfer(string $databaseFilename): void
    {
        // os arquivos JSON
        $databaseFilename = self::ROOT_DIRECTORY . "/$databaseFilename";
        $taxAdminDataFilename = self::ROOT_DIRECTORY . "/" . self::$config["taxAdminDataFilename"];
        // transferência
        (new DaoTransferAdminDataFromJsonFile2Database($databaseFilename, $taxAdminDataFilename))->transferAdminData2Database();
        // releitura do banco de dados por uma camada [dao]
        $dao = new DaoTaxWithTaxAdminDataInDatabase($databaseFilename);
        // o banco de dados contém os dados do arquivo JSON
        $this->assertEquals(TaxAdminData::fromJsonFile($taxAdminDataFilename), $dao->getTaxAdminData());
    }
}

    Comentários

    • Linhas 10–12: as classes testadas são importadas. A instrução [use] não carrega as classes; ela apenas permite referir-se a elas por seus nomes curtos;
    • linha 22: a configuração da aplicação é armazenada em um atributo estático (de classe);
    • Linhas 26–35: o método estático [setUpBeforeClass] de [TestCase] é executado uma vez, antes do primeiro teste da classe. Ele lê o arquivo de configuração e carrega os arquivos da aplicação. O curso de PHP 7 realizava essa tarefa no nível superior do arquivo de teste, fora da classe. Com o PHPUnit, esse código é executado quando o PHPUnit carrega o arquivo, em um momento que não está sob nosso controle; o método [setUpBeforeClass] foi concebido para essa finalidade;
    • Linha 31: os testes da camada [dao] exigem dependências do cálculo do imposto (para a classe [DaoTaxWithTaxAdminDataInDatabase]) e da transferência (para a classe [DaoTransferAdminDataFromJsonFile2Database]). As duas listas são combinadas, e depois a função [array_unique] remove as duplicatas;
    • linhas 38–45: a fonte de dados: os arquivos de descrição dos dois bancos de dados;
    • linhas 48–49: o teste [testTaxAdminData] da versão 5 é executado uma vez para cada um dos dois bancos de dados;
    • linhas 71–83: o mesmo vale para o teste de transferência dos dados do arquivo JSON para o banco de dados.
