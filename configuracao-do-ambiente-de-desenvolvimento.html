    2. Configuração do ambiente de desenvolvimento

    Os scripts foram escritos e testados no seguinte ambiente:

    • um ambiente de servidor web [Apache] / SGBD [MySQL] / [PHP] 8.5 chamado [Laragon];
    • o editor [Visual Studio Code] e sua extensão [PHP Intelephense];
    • o gerenciador de dependências [Composer], fornecido com o [Laragon], que instala as bibliotecas PHP usadas pelo curso.

    Outras ferramentas (o servidor de e-mail [Mailpit], o SGBD [PostgreSQL] e o servidor [Redis]) só interessam a certos capítulos: sua instalação é descrita nos capítulos correspondentes.

    2.1. Instalação do Laragon

    [Laragon] é um pacote para [Windows] que reúne vários componentes de software:

    • um servidor web ([Apache]). Vamos usá-lo para escrever scripts web em PHP;
    • o SGBD [MySQL] ([PostgreSQL] pode ser adicionado a ele, veja o capítulo sobre a versão 6);
    • a linguagem de script PHP, em várias versões, incluindo a versão 8.5;
    • um servidor [Redis] que implementa um cache para aplicações web;
    • a ferramenta [Composer];
    • um terminal de linha de comando no qual todas essas ferramentas podem ser usadas diretamente.

    [Laragon] pode ser baixado em https://laragon.org/download/. Seu uso é gratuito, com todos os recursos; de vez em quando aparece um aviso pedindo a compra de uma licença para apoiar o desenvolvimento, o que é opcional. A instalação é simples: basta aceitar as configurações padrão. [Laragon] é então instalado na pasta [C:\laragon], que chamaremos de <laragon> daqui em diante:

    1
2
3
4
5
6
    C:\laragon
├── bin\        the software: apache, mysql, php, redis, composer…
├── data\       the DBMS data
├── etc\        configuration files
├── tmp\
└── www\        the root of the Apache web server: http://localhost

    Ao iniciar o [Laragon] , sua janela principal é exibida:

    • O botão [Démarrer tout] (Iniciar tudo) inicia o servidor web [Apache], bem como o SGBD [MySQL]. A janela indica então, para cada um deles, que está ativo e em qual porta escuta: 80 para o [Apache], 3306 para o [MySQL];
    • o botão [Web] exibe a página [http://localhost], que corresponde à pasta [<laragon>/www];
    • o botão [Base de données] (Banco de dados) abre uma ferramenta de administração de bancos de dados ([HeidiSQL], incluída no [Laragon]);
    • o botão [Terminal] abre um terminal de comandos no qual [php], [composer], [mysql]… podem ser usados diretamente;
    • o botão [Racine] (Raiz) abre o explorador de arquivos do [Windows] na pasta [<laragon>/www]. É nela que você deve colocar todas as aplicações web gerenciadas pelo servidor [Apache] do [Laragon];
    • Clicar com o botão direito na janela (ou no ícone do [Laragon] na barra de tarefas) abre o menu do [Laragon], que dá acesso às configurações de cada aplicação.

    2.1.1. Seleção do PHP 8.5

    O [Laragon] pode conter várias versões do PHP. A versão a usar é selecionada no menu, na seção [PHP > Version]. Selecione a versão 8.5 (a mais recente da série 8.5). Ela será então usada tanto pelo servidor [Apache] quanto pelo comando de terminal [php] .

    Para que o comando [php] também possa ser usado nos terminais do [VS Code], a pasta do PHP deve estar no PATH do [Windows]. [Laragon] cuida disso: [Tools > Path > Add Laragon to Path]. Depois, abra um novo terminal (os terminais já abertos não enxergam a mudança) e digite:

    1
    > php -v

    O comando deve exibir a versão do PHP, 8.5.x.

    2.1.2. Configuração do PHP para o treinamento

    O PHP é configurado por um arquivo de texto chamado [php.ini], acessível pelo menu do [Laragon], na seção [PHP > php.ini]. Durante o treinamento, o PHP deve relatar todos os erros, avisos e descontinuações. Verifique se o arquivo contém as linhas a seguir (ou modifique-o):

    1
2
3
4
5
6
    error_reporting = E_ALL
display_errors = On
display_startup_errors = On
log_errors = On
error_log = C:/laragon/tmp/php_errors.log
date.timezone = Europe/Paris
    • [error_reporting = E_ALL]: o PHP relata tudo, inclusive as mensagens [Deprecated] que anunciam recursos descontinuados. Uma configuração de produção costuma usar [E_ALL & ~E_DEPRECATED], que as oculta: não é o que queremos aqui;
    • [display_errors = On]: as mensagens são exibidas na saída do script (o terminal ou a página web);
    • [log_errors = On]: as mensagens também são gravadas no log de erros;
    • [error_log]: o arquivo de log. Sem essa linha, um script de console grava seu log no próprio terminal, e cada mensagem apareceria ali duas vezes (uma precedida por [PHP], outra sem ele);
    • [date.timezone]: o fuso horário usado pelas funções de data.

    O curso também usa várias extensões do PHP. Elas são ativadas no menu do [Laragon], na seção [PHP > Extensions], ou no arquivo [php.ini] por meio de linhas da forma [extension=name]. As extensões usadas são: [curl], [mbstring], [openssl], [pdo_mysql], [pdo_pgsql], [fileinfo] e [zip] (esta última é usada pelo [Composer] para descompactar as bibliotecas que ele baixa). Depois de modificar o arquivo [php.ini], é preciso reiniciar o [Apache] (o botão [Reload] do [Laragon]); já os scripts de console relêem o arquivo [php.ini] a cada execução.

    Você pode verificar a configuração em um terminal com o comando [php --ini] (o arquivo [php.ini] utilizado) e [php -m] (a lista das extensões carregadas). O primeiro script do próximo capítulo, [phpinfo.php], exibe toda a configuração.

    2.2. Instalação do VS Code

    O [Visual Studio Code] é um editor gratuito da Microsoft, disponível para download em https://code.visualstudio.com/. Aqui, ele substitui o IDE [NetBeans] usado no curso de PHP 7.

    Depois de instalar o [VS Code] , adicione o suporte à linguagem PHP: no painel [Extensions] (Ctrl+Shift+X), procure e instale a extensão [PHP Intelephense]. Ela oferece:

    • autocompletar de código: funções, classes, métodos e atributos do PHP são sugeridos enquanto você digita;
    • exibição da documentação de uma função ou método ao passar o mouse sobre o nome;
    • detecção de erros durante a digitação (variáveis indefinidas, tipos incorretos, métodos inexistentes etc.), que são sublinhados no código e listados no painel [Problems];
    • navegação no código: pressionar Ctrl+clique no nome de uma classe ou função abre sua definição, inclusive as das bibliotecas da pasta [vendor].

    O [Intelephense] precisa conhecer a versão do PHP em uso para identificar seus novos recursos: nas configurações do [VS Code] (Ctrl+vírgula), pesquise “intelephense php version” e informe 8.5.

    Em seguida, abra a pasta do código do curso no [VS Code] (menu [File > Open Folder]). Um terminal é aberto pelo menu [Terminal > New Terminal]: ele já aponta para a pasta aberta, e você digita os comandos [php], [composer], [curl]… Para executar um script de console, navegue até sua pasta (comando [cd]) e digite [php script-name.php].

        "zbateson/mail-mime-parser": "^3.0"

    "require-dev": {
        "phpunit/phpunit": "^12.0"
    },
    "config": {
        "sort-packages": true
    }
}
    • Linha 6: as bibliotecas necessárias para executar os scripts. Cada uma é identificada por um nome da forma [vendor/library] e por uma restrição de versão: [^8.0] significa “qualquer versão 8.x a partir da 8.0”. O papel de cada uma é descrito nos capítulos que as utilizam;
    • linha 7: o projeto exige o PHP 8.5 ou posterior;
    • linha 15: bibliotecas usadas somente no desenvolvimento, neste caso o framework de testes [PHPUnit].

    Para instalar essas bibliotecas, abra um terminal na pasta [php8-oct-2026] (o terminal do [Laragon] ou o terminal do [VS Code]) e digite:

    1
    > composer install

    O [Composer] cria então uma pasta chamada [vendor] contendo as bibliotecas e suas dependências, além de um arquivo chamado [vendor/autoload.php]. Um script que queira usar essas bibliotecas só precisa incluir esse arquivo, que carrega automaticamente suas classes na primeira vez que são usadas. Os scripts deste curso fazem isso com um caminho relativo à sua própria pasta, por exemplo:

    1
    require_once __DIR__ . '/../../vendor/autoload.php';

    A constante [__DIR__] designa a pasta do script que a utiliza: assim, o caminho não depende da pasta em que o script é executado, nem de onde está a pasta [php8-oct-2026].

    Verifique a instalação exibindo a versão do [PHPUnit]:

    1
2
    > php vendor/bin/phpunit --version
PHPUnit 12.5.37 by Sebastian Bergmann and contributors.
